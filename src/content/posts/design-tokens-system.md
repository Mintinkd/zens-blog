## 令牌是设计的「单一事实来源」

设计令牌（Design Token）是把设计决策抽象成具名变量的实践。它让「品牌蓝」在全平台只定义一次：

```css
--brand: #0052d9;
--brand-soft: #e6edff;
```

## 分层组织

- **原始层**：具体色值，如 `#0052d9`；
- **语义层**：用途命名，如 `--brand`、`--text-1`；
- **组件层**：按钮、卡片等具体消费。

组件永远只引用语义层，这样换肤、换品牌都不用动组件。

## 导出到多端

令牌沉淀为 JSON 后，可以编译成 CSS 变量、iOS 的 `UIColor`、Android 的 `color` 资源，保证三端一致。

> 一套令牌，多端消费——这是规模化产品的隐形基建。

把令牌管好了，设计与研发的协作摩擦会大幅下降。
